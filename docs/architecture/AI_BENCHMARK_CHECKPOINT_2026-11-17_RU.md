## Что сохранено в checkpoint

- В корневом `settings.gradle.kts` подключён отдельный модуль `:ai-benchmark`.
- `:ai-benchmark` — отдельное Android application module с `minSdk 33`, `compileSdk 36`, Java/Kotlin target 17.
- Основной `:app` остаётся на `minSdk 26`; его Gradle-конфигурация не повышалась и не получала inference-зависимостей.
- У benchmark-приложения нет INTERNET permission, Room и доступа к данным портфеля.
- Есть системный выбор GGUF-файла, потоковый SHA-256, ручная сверка с ожидаемым хешем и экран показателей RAM/PSS/свободного места.
- Разрешение на выбранный документ не сохраняется постоянно.

## Подтверждённые требования и устройство

- Целевой телефон: Samsung Galaxy A34, SM-A346E.
- Пользователь подтвердил 8 ГБ физической RAM (не RAM Plus).
- Первый кандидат для теста: Qwen3 1.7B GGUF Q4; точный файл, revision, источник и SHA-256 ещё должны быть зафиксированы отдельно.
- Только локальный inference. Не использовать платные API, backend, облачные модели, подписки или передачу портфельных/новостных данных внешнему ИИ.
