# Источники локальных логотипов

Логотипы хранятся в `app/src/main/assets/logos/` и отображаются офлайн. В каталог приложения добавляются только отдельные векторные изображения, сопоставление тикера проверяется тестом; непроверенные компании не получают чужой логотип.

## Уже включённые источники

| Тикер | Компания | Файл | Источник файла / идентификация |
|---|---|---|---|
| GAZP | Газпром | `gazprom.svg` | Logotyp.us: https://logotyp.us/logo/gazprom/ ; официальный сайт компании: https://www.gazprom.com/ |
| LKOH | Лукойл | `lukoil.svg` | Logotyp.us: https://logotyp.us/logo/lukoil/ ; официальный сайт компании: https://www.lukoil.com/ |
| ROSN | Роснефть | `rosneft.svg` | Logotyp.us: https://logotyp.us/logo/rosneft/ ; официальный сайт компании: https://www.rosneft.ru/ |

Исходные SVG получены из открытого репозитория logotyp.us (kuleyu/site-logotypus, commit `e429d91b144d42abfca5ea66eca2c2582f37aa01`). Перед выпуском каждый файл проверяется на корректность SVG и включение в APK. Официальный сайт указан для проверки соответствия бренду; наличие файла в каталоге не означает аффилированности с эмитентом.

## Ещё не добавлены

MTSS (МТС) и MGNT (Магнит) остаются без сопоставления до проверки подходящего актуального логотипа. Не подменять текущий фирменный знак МТС устаревшей версией с яйцом.
